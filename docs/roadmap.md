# Roadmap

## 0.1 — Public MVP

- hierarchical memory tree;
- typed graph links;
- BFS, DFS and best-first retrieval;
- path allow/deny policies;
- contextual incident matching;
- in-memory store.

## 0.2 — Experiential memory semantics

- structured interaction episodes;
- accepted, rejected, partial, and unknown user outcomes;
- deterministic contrast extraction;
- relational discriminator detection;
- evidence-aware causal claims;
- unknown root causes;
- capsule admission gate;
- scoped activation semantics.

## 0.3 — Pattern memory

- causal signatures;
- cross-context pattern matching;
- duplicate-pattern avoidance;
- independent support counts;
- counterexample and contradiction tracking;
- pattern lifecycle and lineage.

## 0.4 — Visions and preventive retrieval

- Vision resolver;
- deterministic branch pruning;
- A*-style routing;
- deferred frontier cache;
- evidence-group-aware belief updates;
- traversal budgets;
- minimal Memory Preflight.

## 0.5 — Evaluation

- global semantic baseline;
- scoped retrieval baseline;
- Vision and pattern routing benchmark;
- wrong-fix reuse rate;
- context contamination rate;
- false-pruning rate;
- repeated-known-error rate;
- visited-node and injected-token cost.

## 0.6 — Persistence

- SQLite adapter;
- append-only capsule, claim, pattern, and Vision lifecycle journal;
- deterministic snapshots;
- JSONL import/export;
- migrations;
- optional encrypted private store.

## 0.7 — Agent integrations

- provider-neutral preflight compiler;
- Council integration;
- OpenAI Agents and Codex workflow examples;
- LangGraph adapter.

## 1.0

Stable API, persistent adapters, public benchmark report, private-data guidance, and production safeguards.
