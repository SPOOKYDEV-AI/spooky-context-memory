# Situational Memory

A situation is a bounded sequence of contexts serving one objective.

## Phases

```text
exploration
→ convergence
→ implementation
→ validation
→ closed
```

Controlled backward transitions are allowed when validation or implementation exposes a missing assumption.

## Context Contract

The contract is the durable handrail across phases. It preserves need, invariants, discriminating properties, forbidden effects, criteria, decisions, rejected paths, and unresolved questions.

## Handoffs

A phase handoff records retained, compacted, and dormant frames plus risks and required checks. The next phase therefore receives denser context without losing the original goal.
