# Memory Reconstruction

A capsule is stored evidence. A remembered context is a present-time reconstruction.

The reconstructor selects:

- current constraints;
- high-relevance active or dormant contexts;
- active applicable capsules;
- supported patterns;
- shortest transition path;
- unresolved applicability conditions.

It emits bounded sections:

```text
Current need
Must preserve
Historical warnings
Do not repeat
Relevant decisions
Transition path
Unknowns
```

Raw transcripts and complete capsules remain out of the prompt unless explicitly requested for diagnosis or audit.
