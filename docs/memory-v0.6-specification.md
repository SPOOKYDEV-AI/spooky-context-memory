# v0.6 Specification — Global Coherence, Reflective Learning, and Adaptive Unlearning

## Purpose

This milestone completes the adaptive cognitive loop established in v0.5.

```text
Context
→ Global understanding
→ Distributed attention
→ Multiple Views
→ Cross-View triage
→ Action and observed outcome
→ World learning
→ Reflective learning
→ Habit detection
→ Contextual unlearning and relearning
→ Global-understanding revision gate
→ Next context cycle
```

## Context remains the key

All learning, reflective policy, habit activation, unlearning, and recovery are scoped by context fingerprints, discriminators, truth revisions, and project scope.

No success, failure, or cognitive strategy becomes universal merely through repetition.

## Stability through global understanding

Local memory remains plastic. Stability is reconstructed through a slower `GlobalUnderstandingState` containing identity, goals, invariants, truths, patterns, claims, unresolved questions, and a semantic backbone.

Local changes are frequent. Global replacements are slow, evidence-aware, versioned, and reversible.

## Learning in mirror mode

The engine records cognitive trajectories and learns which attention distributions, View compositions, verification sequences, and budgets produced grounded success.

Mirror learning is blocked without external grounding and never turns outcome success into causal proof automatically.

## Unlearning

The engine detects entrenched cognitive habits and distinguishes:

- historical usefulness;
- present applicability;
- predictive reliability;
- context drift;
- contradiction pressure;
- automaticity.

It can inhibit, narrow, weaken, quarantine, supersede, reopen unknown, and coordinate relearning while preserving history and recovery conditions.

## Required invariants

1. Context controls applicability, learning, reflection, and unlearning.
2. Local memory may move continuously while global coherence remains stable.
3. Global understanding is revisable but changes more slowly than Views.
4. A good outcome does not prove a causal explanation.
5. Mirror learning requires external grounding.
6. Reflective strategies remain context-specific.
7. Correlated success or failure counts once per independence group.
8. A habit can lose automatic authority without losing historical truth.
9. Unlearning is reversible unless durable supersession is established.
10. Counterfactual Views preserve the habitual path as a control.
11. Returning to unknown is epistemically valid.
12. Private runtime memory never enters the public repository.
