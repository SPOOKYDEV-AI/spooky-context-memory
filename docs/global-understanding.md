# Global Understanding and Coherence

A living memory is not stable because its nodes never move. It is stable when local movement preserves a coherent understanding of the whole situation.

```text
Local attention and Views change quickly
Memory links and capsules change progressively
Patterns change more slowly
Global understanding changes only under sufficient pressure
```

## Global understanding is an attractor

`GlobalUnderstandingState` contains one dominant model and optional alternatives. A model is not a universal truth. It is the most coherent current explanation of:

- the subject and primary goal;
- the current situation;
- protected invariants;
- active truth anchors;
- core recurring patterns;
- accepted, alternative, and disputed claims;
- unresolved questions;
- the semantic backbone connecting these elements.

The dominant model acts as a coherence attractor. New Views may depart from it, but they do not destabilize the whole memory unless they bring independent contradiction, context drift, truth changes, or a better alternative model.

## Different plasticity speeds

- Attention is fast and highly contextual.
- Views are temporary and disposable.
- Plastic links and capsules are incrementally revised.
- Patterns are relatively stable.
- Global understanding has inertia but remains revisable.

A local contradiction should normally revise a View, claim, or link. A global revision requires independent pressure on structural elements.

## Global Revision Gate

The revision gate distinguishes:

- `maintain`: local movement is compatible with the current model;
- `local_revision`: affected claims or backbone edges change without replacing the model;
- `challenge_dominant`: coherence fell below its protected band;
- `promote_alternative`: an existing alternative explains the context better by a sufficient margin;
- `global_revision`: independent contradiction pressure justifies a controlled replacement.

Historical models are preserved as alternatives or challenged models. They are not silently overwritten.

## Semantic backbone

The semantic backbone stores relatively stable structural relations such as:

- depends on;
- causes;
- constrains;
- explains;
- excludes;
- enables;
- preserves;
- supersedes.

Backbone edges retain independent support and challenge keys. Repeated correlated signals count once. A disputed edge remains historically available until it is explicitly superseded or archived.

## Central invariant

> Memory elements may move continuously, but each movement must either preserve global coherence or provide enough evidence to justify revising it.
