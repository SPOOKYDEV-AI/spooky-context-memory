# Adaptive Unlearning

Learning builds useful paths. Unlearning prevents those paths from becoming prisons.

Unlearning does not mean deleting history. It means reducing automatic influence when a strategy is no longer justified by the current context.

```text
Forget      → lose information
Unlearn     → remove unjustified automatic authority
Relearn     → build a better contextual policy from preserved history
```

## Cognitive habits

A `CognitiveHabit` connects a contextual signature to preferred attention, View, and action patterns. It tracks:

- historical support;
- current applicability;
- predictive reliability;
- contradiction pressure;
- context drift;
- automaticity;
- adaptability;
- independent success and failure keys.

Historical support and present applicability are intentionally separate.

## Context-first unlearning

The engine asks:

- Is the habit false?
- Is it obsolete?
- Is it still valid in a narrower scope?
- Is only its automatic activation harmful?
- Did a better strategy supersede it?

Possible actions are:

- retain;
- challenge;
- contextually inhibit;
- narrow;
- weaken;
- quarantine;
- supersede;
- reopen as unknown;
- relearn.

A single failure normally challenges a habit. Repeated independent failures, context drift, truth supersession, or a superior strategy are required for stronger actions.

## Controlled dehabituation

When a habit is challenged, the system can generate counterfactual Views:

1. the habitual path as a control;
2. a path without the habit;
3. an inverted-assumption path;
4. a fresh path built only from current truths and context.

The habitual path remains available for comparison. It is not deleted merely because it is temporarily inhibited.

## Relearning and recovery

Every reversible inhibition stores:

- why it happened;
- the affected context;
- triggering observations;
- preserved historical support;
- reactivation conditions.

A recovered habit returns as `challenged`, not immediately as an automatic default. It must earn applicability again through current evidence.

## Safety invariants

- No irreversible unlearning from one failure.
- Inhibition precedes deletion or supersession where possible.
- Historical truth is preserved even when operational authority falls.
- Correlated failures count once.
- Reopening `unknown` is valid when previous evidence no longer supports certainty.
- Every contextual inhibition has explicit recovery conditions.
